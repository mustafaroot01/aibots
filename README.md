# موقع وظائف ديالى — سحب تلقائي من قناة تلجرام

موقع وظائف عربي (RTL) يسحب المنشورات من قناة تلجرام عامة، يفلترها بالذكاء الاصطناعي
(Claude)، يستخرج منها بيانات منظمة (المسمى الوظيفي، المحافظة، الراتب، رقم التواصل...)،
وينشرها مباشرة بالموقع مع بحث وفلاتر.

القناة الحالية: [@Diyala_jobs](https://t.me/Diyala_jobs)

---

## الستاك المستخدم وليش

| الطبقة | التقنية | السبب |
|---|---|---|
| السحب | `fetch` + `cheerio` على صفحة `t.me/s/<channel>` | القناة عامة، فما نحتاج بوت ولا حساب ولا `api_id` — صفر صلاحيات |
| الفلترة | **Gemini أو Claude** + مخرجات JSON منظمة | يفهم اللهجة العراقية والمنشورات الفوضوية ويرجع بيانات مضمونة الشكل |
| احتياطي | فلترة بالكلمات المفتاحية | إذا انقطع الـ API أو خلص الرصيد، الموقع يضل يشتغل |
| قاعدة البيانات | SQLite عن طريق `node:sqlite` المدمج | ملف واحد، بدون سيرفر قاعدة بيانات، وبدون أي مكتبة native تحتاج بناء |
| الموقع | Next.js 15 (App Router) + CSS خام | RTL كامل، SSR سريع، أرشفة قوية بمحركات البحث |
| التشغيل | pm2 + nginx | عمليتين: الموقع + عامل الخلفية |

**متطلب مهم:** Node.js نسخة **23.4 أو أحدث** (يُنصح بـ Node 24 LTS) لأن `node:sqlite` مدمج بيها.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local     # وحط مفتاح Claude داخله
npm run ingest                 # دورة سحب وفلترة وحدة
npm run backfill 10            # (اختياري) يسحب 10 صفحات من أرشيف القناة
npm run dev                    # الموقع على http://localhost:3000
```

بنافذة ثانية شغّل العامل حتى يضل يتابع القناة:

```bash
npm run worker
```

### الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run ingest` | دورة وحدة: سحب ← فلترة ← نشر |
| `npm run worker` | يشتغل دائم، يفحص القناة كل `POLL_SECONDS` ثانية |
| `npm run backfill 10` | يسحب الأرشيف القديم صفحة صفحة |
| `npm run reclassify` | يعيد فلترة المرفوضات (بعد ما تعدّل البرومبت) |
| `npm run reclassify all` | يعيد فلترة **كل** المنشورات من الأول |
| `npm run fix-phones` | يعيد استخراج الأرقام وينظّف العناوين بدون أي كلفة API |
| `npm run build && npm start` | نسخة الإنتاج |

## شلون تشتغل الفلترة

كل منشور يمر على Claude مع مخطط JSON ثابت، والموديل يقرر:

- **ينشر** إذا: إعلان شاغر حقيقي (مطلوب، نحتاج، تعيينات...) وثقة ≥ 0.5
- **يرفض** إذا: شخص يدور على عمل، إعلان تجاري/بيع/إيجار، دورة مدفوعة، تسويق شبكي،
  نصب، أخبار، أو منشور بلا نص

ويستخرج: المسمى الوظيفي، الشركة، المحافظة، المنطقة، القسم، نوع الدوام، الجنس المطلوب،
الراتب، الخبرة، عدد الشواغر، أرقام الهاتف (موحّدة بصيغة `07XXXXXXXXX`)، طريقة التقديم،
ملخص، وكلمات مفتاحية.

**تعديل قواعد الفلترة**: كل الكلام موجود بمتغير `SYSTEM` داخل `src/lib/classify.ts` —
عدّله بالعربي عادي، وبعدها شغّل `npm run reclassify all` حتى يعيد تصنيف كل شي.

### الكلفة التقريبية (٣٠ منشور باليوم، دفعة ٥ بالطلب)

| الموديل | بالشهر |
|---|---|
| Gemini 2.5 Flash (بدون تفكير) | **$0.76** — ومجاناً ضمن الباقة المجانية |
| Gemini 3.5 Flash | $0.58 |
| Gemini 2.5 Flash (مع تفكير) | $2.29 |

## النشر على السيرفر (VPS)

المفاتيح جاهزة بملف **`deploy/env.production`** (مستثنى من git) — انسخه للسيرفر:

```bash
scp deploy/env.production root@YOUR_SERVER:/var/www/jobs/.env.local
```

بعدها غيّر `ADMIN_TOKEN` و `SITE_URL` داخله. باقي الخطوات:

```bash
# 1) Node 24 + pm2
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm i -g pm2

# 2) المشروع
git clone <repo> /var/www/jobs && cd /var/www/jobs
npm ci
cp .env.example .env.local && nano .env.local     # حط المفاتيح
npm run build
npm run backfill 20                                # يعبّي الموقع بالأرشيف

# 3) التشغيل الدائم
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup

# 4) nginx + SSL
sudo cp deploy/nginx.conf /etc/nginx/sites-available/jobs
sudo ln -s /etc/nginx/sites-available/jobs /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d jobs.example.com
```

المتابعة: `pm2 logs jobs-worker` · النسخ الاحتياطي: انسخ ملف `data/jobs.db` بس.

## لوحة التحكم

`https://your-site.com/admin` — تدخل بـ `ADMIN_TOKEN` مرة وحدة والجلسة تنحفظ بكوكي محمي
(HttpOnly + SameSite) لمدة ٣٠ يوم.

### ١) نظرة عامة
- مؤشرات: المنشورة، المرفوضة، اللي تنتظر مراجعة، اللي انرسلت لقناتك، اللي فشلت.
- **فحص حالة النظام**: يقلك إذا مفتاح Claude مضبوط، والنشر بالقناة شغال، والعامل حي.
- أزرار تشغيل فوري: دورة كاملة · فلترة المنتظر · نشر الطابور · إعادة فلترة.
- سجل آخر عمليات النشر بقناتك مع سبب أي فشل.

### ٢) المنشورات
بحث وتصفية بالحالة وبحالة النشر بالقناة، ولكل منشور: درجة الثقة، سبب القرار، والأزرار:
نشر / إخفاء / رفض / إعادة فلترة / نشر بقناتك / رجّعه للطابور / معاينة.

**المعاينة الإدارية**: وأنت مسجّل دخول تكدر تفتح صفحة أي منشور حتى لو مرفوض أو مخفي أو
قيد الفلترة — يطلعلك شريط تنبيه بحالته وسبب قرار الذكاء الاصطناعي، والصفحة تحمل `noindex`.
الزائر العادي ما يشوف غير المنشور فعلاً.

### ٣) الإعدادات
كل شي يتضبط من الواجهة ويُخزن بقاعدة البيانات — **العامل يقراها كل دورة، فما تحتاج تعيد تشغيل شي**:

| القسم | شنو تضبط منه |
|---|---|
| هوية الموقع | الاسم، الرابط، قناتك، وإظهار/إخفاء رابط المصدر |
| مصدر المحتوى | القناة اللي ننسحب منها، مدة الفحص، صفحات الأرشفة |
| الفلترة والتحليل | الموديل، مستوى الجهد، حجم الدفعة، حد الثقة، النشر التلقائي، كلمات قبول/رفض، تعليمات إضافية للموديل |
| النشر بقناتك | تفعيل، توكن البوت، القناة، القالب، التذييل، الصورة/الأرقام/الرابط، الفاصل الزمني، أقصى عمر للمنشور |
| العرض | عدد الوظائف بالصفحة، إخفاء الأرقام |

كل القيم تتفحص وتتحدد بمدياتها (مثال: مهلة الفحص ما تنزل تحت ٣٠ ثانية)، والتوكن ما ينمسح
إذا خليت الحقل فارغ.

## النشر التلقائي بقناتك الخاصة

كل وظيفة تنشر بالموقع تنرسل **بنفس اللحظة** لقناتك على تلجرام، والمحتوى يطلع باسم قناتك —
**ما يُذكر المصدر أبداً** لا بالموقع ولا بالرسالة.

**متى ينرسل؟** بكل الحالات — تلقائياً لما العامل يلكي وظيفة جديدة ويفلترها وينشرها،
وفوراً لما تضغط «نشر» يدوياً من لوحة المنشورات. المنشور اللي انرسل مرة ما ينعاد إرساله.

**التجهيز:**
1. سوّي بوت من [@BotFather](https://t.me/BotFather) وخذ التوكن.
2. ضيف البوت **أدمن** بقناتك مع صلاحية "نشر الرسائل".
3. من `/admin/settings` ← قسم **النشر بقناتك**: فعّل، حط التوكن واسم القناة.
4. اضغط **فحص الاتصال** ثم **رسالة تجريبية** حتى تتأكد.

**قالب الرسالة** يتعدل من اللوحة، وأي سطر كل متغيراته فارغة ينحذف تلقائياً:

```
💼 <b>{title}</b>
🏢 {company}

📍 {city}
🕒 {type}
💰 {salary}

{summary}

📞 {phones}
🔗 {link}
{footer}
```

المتغيرات المتاحة: `{title}` `{company}` `{city}` `{area}` `{category}` `{type}` `{gender}`
`{salary}` `{experience}` `{vacancies}` `{summary}` `{phones}` `{apply}` `{link}` `{footer}`
`{channel}` `{text}`

**حمايات مبنية بالنظام:**
- فاصل زمني بين الرسائل (افتراضي ٤ ثواني) حتى ما يحظرك تلجرام.
- **أقصى عمر للمنشور** (افتراضي ٤٨ ساعة) — يمنع إغراق قناتك لما تسحب الأرشيف.
- أي فشل ينسجل بسبب واضح، وتكدر ترجّع المنشور للطابور من لوحة المنشورات.

## مزوّد الذكاء الاصطناعي — Gemini أو Claude

الموقع يشتغل بأي واحد منهم، والتبديل من لوحة التحكم بدون أي تعديل كود
(`/admin/settings` ← قسم الفلترة والتحليل).

| المزوّد | المفتاح | من وين | الكلفة (٣٠ منشور/يوم) |
|---|---|---|---|
| **Gemini** (موصى به) | `GEMINI_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | **مجاناً** ضمن الباقة المجانية · أو ~$0.76/شهر مدفوع |
| **Claude** | `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) | ~$0.85–7 حسب الموديل |
| **بدون** | — | — | مجاناً (كلمات مفتاحية بس) |

### إعدادات Gemini
- **الموديل**: `gemini-2.5-flash` افتراضياً (سريع ودقيق). متاح كذلك `gemini-3.5-flash` وغيرها.
- **التفكير العميق**: مطفي افتراضياً — بالتجربة على منشورات حقيقية طلع **نفس الدقة بالضبط**
  بس **أسرع ٣ مرات وأرخص ٣ مرات** (٧ ثواني بدل ٢١ لكل ٥ منشورات).
- **حد الطلبات**: الباقة المجانية تسمح بـ **٥ طلبات بالدقيقة** لكل موديل. النظام ينظّم سرعته
  تلقائياً (افتراضي ٤ طلبات بالدقيقة — هامش أمان)، و**كل طلب يمر من المنظّم بضمنه محاولات الإعادة**.
  إذا رجع خطأ 429، النظام يقرأ مدة الانتظار اللي يطلبها جوجل، يوقف كل الطلبات لهذي المدة،
  ويعيد المحاولة ٦ مرات قبل ما ينزل للكلمات المفتاحية.
  مع دفعة ٨ منشورات بالطلب، هذا يعني **٣٢ منشور بالدقيقة** — أكثر بكثير من حاجة أي قناة.

### التبديل بينهم
إذا اخترت مزوّد وما موجود مفتاحه، النظام يجرب الثاني تلقائياً، وإذا ما موجود ولا مفتاح
ينزل للفلترة بالكلمات المفتاحية — الموقع ما يوقف بأي حال.

بعد تغيير المزوّد أو الموديل: شغّل **«إعادة فلترة الكل»** من لوحة التحكم.

## أرقام الهاتف وصياغة المنشور

### استخراج الأرقام
الأرقام تنسحب من نص الإعلان بمحلل مخصص للأرقام العراقية ([src/lib/phone.ts](src/lib/phone.ts)):

- يفهم **الأرقام العربية** `٠٧٧٦٣٩١١٧٤٤` والفارسية `۰۷۷۰...` ويحولها
- يفهم كل الصيغ: `07704367391` · `0787 744 4197` · `0770-123-4567` · `+964 774 448 4445` · `00964 780 123 4567`
- **يرفض اللي مو أرقام هاتف** — مثل «الراتب 750-1000000» اللي كان ينسحب غلط كرقم
- يتحقق من بادئة الموبايل العراقي `07[3-9]` وطول الرقم (١١ خانة)
- يوحّد كل شي لصيغة `07XXXXXXXXX`، ويعرضه بالموقع `0777 335 9147` مع روابط اتصال وواتساب صحيحة

الأرقام اللي يرجعها الموديل ما نعتمد عليها لوحدها — نسحبها من النص لأن هذا أدق وما ينخدع.
لإصلاح الأرقام والعناوين بالمنشورات القديمة: `npm run fix-phones` (بدون أي كلفة API).

### صياغة رسالة القناة
- **يشيل مخاطبة صاحب القناة** تلقائياً: «السلام عليكم صاحب القناة ياريت تنشرلي…» تنحذف ويبدي الإعلان من «مطلوب…»
- **ما يكرر** رقم الهاتف بسطر التقديم إذا هو نفس الرقم المعروض
- **القص عند حدود الكلمة** مع «…» — ما يقطع بنص كلمة
- يحترم حدود تلجرام تلقائياً: ١٠٢٤ حرف مع صورة، ٤٠٩٦ بدونها — ويقصّ **نص الإعلان بس**، فيبقى العنوان والأرقام والرابط كاملين
- الأحرف الخاصة `< > &` تنهرب حتى ما تكسر تنسيق HTML

## تطبيق الجوال (PWA)

الموقع يتثبّت على الجوال كتطبيق حقيقي:

- **أيقونة على الشاشة الرئيسية** (أندرويد وآيفون) بأيقونات 192/512 + maskable.
- **يشتغل بدون إنترنت** — عامل خدمة يخزّن الصفحات اللي انفتحت، وصفحة أنيقة لما ينقطع النت.
- **زر «ثبّت التطبيق»** يظهر بالهيدر لما المتصفح يسمح.
- شريط علوي بلون الموقع، دعم شاشات النوتش، وواجهة كاملة بدون شريط المتصفح.

الأيقونات تتولد بأمر واحد بدون أي مكتبة: `node scripts/gen-icons.mjs`

- **موبايل أولاً** — كل شي يشتغل بيد وحدة، وأزرار الاتصال والواتساب ثابتة بأسفل صفحة الوظيفة.

## الأمان

### حماية لوحة التحكم
| الطبقة | الشرح |
|---|---|
| **جلسات عشوائية** | معرّف ٦٤ خانة عشوائي مخزّن بقاعدة البيانات — مو هاش ثابت للتوكن. تنتهي بعد ٧ أيام وتتجدد مع الاستخدام |
| **كوكي محمي** | `HttpOnly` + `SameSite=Lax` + `Secure` تلقائياً لما يكون الاتصال HTTPS |
| **قفل بعد المحاولات** | ٥ محاولات فاشلة ← قفل ١٥ دقيقة لهذا الجهاز، مع عدّاد ظاهر بصفحة الدخول |
| **مقارنة بوقت ثابت** | التوكن ينقارن بـ `timingSafeEqual` — ما ينكشف بتحليل التوقيت |
| **حماية CSRF** | مبنية بـ Next (فحص الـ Origin بكل إجراء سيرفر) |
| **بوابة Middleware** | أي طلب لـ `/admin` بدون كوكي جلسة صحيحة الشكل ينعرض له صفحة الدخول قبل ما تنبني اللوحة |
| **حارس بكل صفحة** | كل صفحة إدارة تتحقق من الجلسة مقابل قاعدة البيانات بأول سطر — قبل أي استعلام |
| **خروج من كل الأجهزة** | زر بلوحة الأمان يلغي كل الجلسات فوراً |

### الأسرار
- **توكن بوت تلجرام ينخزن مشفّر** (AES-256-GCM) بمفتاح `SECRET_KEY`. لو انسربت نسخة من
  `data/jobs.db` بدون المفتاح، التوكن ما ينقرأ.
- التوكن **ما ينعرض بالواجهة أبداً** — الحقل يبقى فارغ ويظهر «محفوظ ✓» بس.
- مفاتيح الذكاء الاصطناعي تبقى بملف البيئة على السيرفر، وما تنرسل للمتصفح ولا تنعرض باللوحة.
- أدوات التشخيص محلية (`npx tsx scripts/print-settings.ts`) — **ما موجود أي مسار ويب** يرجع الإعدادات.

### ترويسات الحماية
`Content-Security-Policy` · `X-Frame-Options: DENY` · `X-Content-Type-Options: nosniff` ·
`Referrer-Policy` · `Permissions-Policy` · وإخفاء `X-Powered-By`.
ولوحة التحكم عليها `X-Robots-Tag: noindex` و `Cache-Control: no-store`.

### قبل النشر — إلزامي
1. **غيّر `ADMIN_TOKEN`** لتوكن قوي (١٢ حرف+، حروف وأرقام ورموز): `openssl rand -base64 24`
2. **ولّد `SECRET_KEY`**: `openssl rand -hex 32`
3. **شغّل HTTPS** (certbot) — بدونه الكوكي ما تكون `Secure`
4. لوحة الأمان بصفحة `/admin` تفحصلك هذي كلها وتقلك شنو ناقص
